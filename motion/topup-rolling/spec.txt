ANIMATION SPEC: Top-up rolling counter
Screen / component: eSIM plan card, number row + data meter
Purpose: Confirms the top-up has landed by rolling the balance to its new value.
Trigger: Data event. The user lands back on the plan card after a successful
  top-up (or the card is on screen when the new balance arrives). Plays once,
  300ms after the card is visible. Never on later visits.

Phases (t = 0 when the roll starts, 300ms after the card is on screen):
1. Units reel: translateY, rolls from the old whole number to the new one,
   odometer style, overshoots by 0.25 of a digit, then settles back.
   Roll:   0-1300ms, 0 to steps + 0.25 | Curve: Curves.easeOutCubic
   Settle: 1300-1520ms, back to steps  | Curve: Curves.easeInOutCubic
   The roll is 1300ms however many steps (3 days or 10 GB).
   Motion blur on the units reel while it moves fast:
   blur = min(2px, 0.12 x speed in digits per second), none under 1 digit/s.
2. Data meter fill: follows the roll, from old fraction to new fraction,
   driven by the same controller (progress = rolled steps / steps, clamped
   to 0-1, so it does not overshoot). If the fraction does not change
   (unused plan), the meter does not move.
3. Tens digit (only when the balance goes from one digit to two):
   starts 100ms before the units pass 9.5.
   Tens slot: width 0 to one digit (43.2px), pushing the row right.
   Tens reel: the "1" rises from below into the slot (translateY 76px to 0).
   Duration: 420ms | Curve: Curves.easeOutCubic
   If the balance already had two digits, the tens reel rolls with the
   carry (12 to 22), no entrance.
4. Total label ("/ 3 GB" to "/ 13 GB"): cross-fade, old moves up 14px and
   fades out, new rises 14px into place. 1200-1500ms.
   Duration: 300ms | Curve: Curves.easeOutCubic
   Decimals (".40") stay still: top-ups are whole GB or whole days.

Total: 1520ms after the delay.
Interruption: Never blocks input; the card stays tappable. A new balance
  mid-flight jumps to the end state, then rolls from there to the new value.
  Card leaves the screen: jump to the end state.
Reduced motion (MediaQuery.disableAnimationsOf == true):
  No roll. Old card body (number, label, meter) cross-fades to the new one in
  150ms via AnimatedSwitcher.
Suggested Flutter approach: One AnimationController (1520ms) for roll + settle
  + meter + label (Intervals), one 420ms controller for the tens entrance,
  started when the value passes 9.5 minus 100ms. Reels are ClipRect +
  Transform.translate over a 0-9-0 column, tabular figures. Blur via
  ImageFiltered, optional if it costs frames on low-end Android.
  Reference widget: top_up_data_meter.dart.
Assets: none.
