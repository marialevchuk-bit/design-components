# Hubby home hero animations

Drop this folder into the repo (for example `docs/animations/`), then ask Claude Code:

> Implement the four home hero animations in Flutter following docs/animations/SPEC.md. Use the .html files as the visual reference. The colour must come from the partner theme.

- `activate-download/`: "Ready to activate" hero
- `setup-toggles/`: "Ready to set up" hero
- `travel-flight/`: "Ready to travel" hero
- `connect-signal/`: "Ready to connect" hero
- `preview.html`: all four side by side, with replay, 0.25× slow motion and a reduced-motion toggle
- `SPEC.md`: layers, timings, easing, reduced motion, Flutter notes
